# Perfect Chess

A modern chess platform built with Next.js focused on chess skill improvement 

## Features

- Puzzle trainer
- Lessons and courses system
- Progress tracking
- Video learning support

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Custom components and hooks

## Project Structure

app/            pages and routing  
components/     UI and chess features  
hooks/          custom hooks  
lib/            core logic  
utils/          game logic and tracking  
public/         static assets  
styles/         global styles  

## Installation

```bash
git clone https://github.com/muhammed-rasal68/perfect-chess.git
cd perfect-chess
npm install
npm run dev
```

## Usage

http://localhost:3000
